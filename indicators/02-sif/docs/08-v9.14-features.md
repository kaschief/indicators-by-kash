# SIF Hunter° v9.14 - Source Filtering & Multi-Source Highlighting

## 🆕 New Features

### 1. Source Filter
**Location:** 🎯 Directional Filter section

**Purpose:** Filter SIFs based on gap source count to focus analysis on specific zone types.

**Options:**
- **"All"** - Display all SIFs (default behavior)
- **"Single-Source Only"** - Show only SIFs formed from one gap source (clean zones)
- **"Multi-Source Only"** - Show only SIFs formed from multiple gap sources (confluence zones)

**Use Cases:**
- **Clean Analysis:** Use "Single-Source Only" to focus on clear, unambiguous zones
- **Confluence Trading:** Use "Multi-Source Only" to identify high-probability confluence areas
- **Full Analysis:** Use "All" for complete market structure visibility

### 2. Multi-Source SIF Highlighting  
**Location:** ✨ SIF Extension section

**Purpose:** Visually distinguish confluence zones with enhanced borders.

**Features:**
- **Toggle:** "Highlight Multi-Source SIFs" (enabled by default)
- **Color:** Customizable border color (orange by default)
- **Visual Enhancement:** 2px borders for multi-source SIFs vs 1px for single-source

**Behavior:**
- **Single-source SIFs:** Standard 1px borders in normal colors
- **Multi-source SIFs:** Enhanced 2px borders in highlight color (when enabled)

### 3. 🚨 Multi-Source SIF Alerts
**Purpose:** Automatic alerts for confluence zones with multiple gap sources.

**Alert Types:**
- **"Multi-Source SIF+"** - Bullish confluence zones
- **"Multi-Source SIF-"** - Bearish confluence zones

**Trigger Logic:** Automatically fires when consolidated SIFs have multiple gap sources
**No Configuration:** Alerts are always active (no toggle needed)
**Message Format:** "Multi-Source SIF+ at {interval} | Price: {close}"

## 🔧 Technical Details

### SIF Classification
- **Single-Source SIF:** Formed from one gap type (e.g., FVG alone, Implied alone)
- **Multi-Source SIF:** Formed from multiple gap types on same candle (e.g., FVG + Implied, FVG + Volume)

### Important Notes
- **Filters affect visuals only** - All detection and alerts continue for all SIFs
- **SUPER SIF checkmarks preserved** - ✔️ indicators remain visible regardless of filters
- **Performance optimized** - Source count cached to avoid redundant calculations
- **Backward compatible** - All existing v9.13 functionality preserved

### Filter Logic Flow
1. **Source Filter Check:** Determines if SIF should be displayed based on source count
2. **Individual SIF Validation:** Preserves all existing v9.13 filtering (invalidation, source toggles, etc.)
3. **Final Display:** SIF shown only if both checks pass

### Border Enhancement Logic
1. **Source Count Analysis:** Counts gap sources in SIF group
2. **Highlighting Check:** Applies enhanced borders if multi-source and highlighting enabled
3. **Fallback:** Uses standard borders if single-source or highlighting disabled

## ⚙️ Settings Reference

### Source Filter Settings
- **Control:** Dropdown in Directional Filter section
- **Default:** "All"
- **Impact:** Visual display only (detection continues for all)

### Multi-Source Highlighting Settings
- **Enable Toggle:** "Highlight Multi-Source SIFs" (default: ON)
- **Border Color:** Customizable (default: Orange)
- **Border Width:** 2px for multi-source, 1px for single-source
- **Impact:** Visual enhancement only

### 🚨 Multi-Source Alert Settings
- **Alert Types:**

  - "Multi-Source SIF-" - Bearish confluence zones
- **Trigger Logic:** Automatically fires when consolidated SIFs have multiple gap sources
